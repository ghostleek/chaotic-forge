## Runtime and persistence contracts

Freeze parent build, cards, and pending additions; generate outside gameplay. Persist jobs and promote exactly one validated immutable artifact per accepted room revision. Duplicate, canceled, or obsolete results cannot replace a newer build. Failed jobs preserve the last playable build and pending choices for visible recovery; never promise instant output.

Preserve earlier rules across additions. Run untrusted generated browser code through an isolated artifact host with validated messages, never the application origin. Score validation also uses bounded isolated execution, never unrestricted generated code in the room Worker. Qualify those hosts rather than assume availability.

Store exact manifests, executable bundles, assets, and lineage; R2 may hold actual dynamic artifacts, with D1 metadata. Replay loads retained versions without regeneration. Preset fallback stays visibly labeled and leaves this target milestone incomplete.
