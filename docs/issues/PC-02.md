# PC-02 — Resolve concept cards into a real playable demo manifest

**Status:** Local issue draft; no GitHub issue/PR created, verified, or assigned.
**Proposed accountable owner / implementer:** Lance. **Reviewer:** Kahhow, independent of implementation.

## Outcome

The three selected FPS/Zombies/Cooking card variants resolve to an executable game with real interactions. Every supported starting combination works, later cards change the simulation, and the result remains reconstructible from an immutable manifest.

Read [PRD](../../PRD.md), [PLAN](../../PLAN.md), [QUALITY](../../QUALITY.md), [AGENTS](../../AGENTS.md), `lib/mechanics/dash-runtime.ts`, its existing tests, and the runtime/provenance findings in [prior review](../../archive/2026-09-13-mechanic-lab/mechanic-forge-pr-review.md). The existing dash experiment remains untouched.

Preserve catalog/resolver/runtime/asset version references. A saved manifest must later run without regenerating or silently adopting changed rules. Do not imply the old dash or ModeShift runtime already implements this mashup.
